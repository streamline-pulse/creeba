## Composable packages

Creeba ships as small packages under the `@streamline-pulse` scope, split so that
native/ORM dependencies never leak into environments that can't use them.

<CardGrid>
  <Card title="creeba-core" icon="seti:typescript">
    Portable P2P core: identity, presence, peers, routing of opaque payloads over
    a pluggable `SyncTransport`. No native dependency.
  </Card>
  <Card title="creeba-iroh-mdns" icon="seti:powershell">
    Bun/Node transport: encrypted QUIC (iroh) with serverless LAN discovery over
    mDNS, plus ed25519 identity helpers.
  </Card>
  <Card title="creeba-oplog" icon="seti:clock">
    Portable op-log: hybrid logical clock, operation journal, LWW convergence.
    Persistence-agnostic.
  </Card>
  <Card title="creeba-oplog-prisma" icon="seti:db">
    Prisma binding: transparent mutation capture, ready-made `OpStore` and
    `Projection`.
  </Card>
</CardGrid>
